# 27 hero image prompts — paste these

**This is the only file you need open while generating story art.**
27 prompts, one per story card. Everything else is reference.

---

## Before you paste anything

| | |
|---|---|
| **Size** | **1536 × 1024** — ask for "wide landscape 3:2" every time |
| **Format** | PNG, **opaque** (no transparency) |
| **Text in image** | **NONE.** No titles, no letters, no numbers, no watermark |
| **Composition** | characters on the **LEFT and CENTRE** — the card's title sits on the right |
| **Save to** | `missingassets/dropin/Stories_Art/` using the **exact filename in each heading** |

**Do all 27 in ONE chat session, in order.** That is what keeps the style consistent. If one comes
back wrong (different outline weight, muted colours, 3D-render look) regenerate it immediately —
do not plan to fix it later, the whole set has to look like one book.

⚠️ **#12 and #15 are the same story** (*In Grandfather's Day*, the researcher's doc has two
versions). The prompts below deliberately make them look different — photo album on the couch vs.
birthday cake. Keep it that way or learners will think it is a duplicate.

Leave `s01_easy`, `s01_average`, `s01_hard` alone. Those are already real art.

---

## When you are done

```powershell
powershell -ExecutionPolicy Bypass -File missingassets/install.ps1
```

It copies each file over the existing placeholder and **never touches the `.png.meta`** (that file
holds the GUID and the Sprite import setting — delete it and the picture will not draw). A
filename the game does not ask for is rejected rather than installed, because a typo is the one
mistake that silently leaves a card blank.
